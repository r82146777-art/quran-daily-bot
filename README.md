# ربات روزانه قرآن کریم

این ربات هر روز ساعت ۸ صبح (به وقت ایران) یک صفحه از قرآن کریم را همراه با:

- متن عربی (رسم‌الخط عثمانی)
- ترجمه فارسی (فولادوند)
- صوت استاد عبدالباسط عبدالصمد

به کانال تلگرام ارسال می‌کند.

## کانال
[t.me/mahfeluoran](https://t.me/mahfeluoran)

## راه‌اندازی

1. ربات را **ادمین** کانال کنید (با دسترسی ارسال پیام).
2. در گیت‌هاب به بخش **Settings → Secrets and variables → Actions** بروید و این دو تا رو اضافه کنید:
   - `TELEGRAM_BOT_TOKEN` → توکن ربات
   - `TELEGRAM_CHANNEL_ID` → آیدی عددی کانال (`-1003040950176`)
3. Workflow روزانه به صورت خودکار اجرا می‌شود.

## اجرا دستی
از تب Actions می‌توانید workflow را دستی هم اجرا کنید.
